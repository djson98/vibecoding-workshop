복사용 프롬프트

이 폴더는 Zotero에서 Obsidian으로 가져온 논문 Markdown 노트입니다. 각 노트의 서지정보, 초록, 하이라이트, 메모를 읽고 노트 사이의 연결을 만들어줘. 1. 반복해서 등장하는 핵심 개념을 뽑아줘. 2. 같은 개념을 다루는 논문들을 묶어줘. 3. 각 논문 노트에 연결하면 좋은 [[개념 노트]]를 제안해줘. 4. 서로 비교할 만한 논문 쌍을 찾아줘. 5. Obsidian에서 쓸 수 있는 [[링크]] 형태로 연결 예시를 만들어줘. 근거가 된 노트 이름을 [[노트명]] 형태로 표시해줘.
