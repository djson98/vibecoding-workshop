# Week 5 오프라인 실습 데이터

Connector 또는 MCP 연결이 안 될 때 사용하는 대체 자료입니다.

## 파일

- `운영-요청.md`: 업무 요청 조건
- `참가자-현황.csv`: 점검할 표 데이터
- `업무노트-템플릿.md`: 결과 노트 형식

## 시작 프롬프트

```text
week5/sample-data 폴더를 읽어줘.

먼저 파일 목록과 각 파일의 역할을 설명하고,
운영-요청.md의 기준에 따라 참가자-현황.csv를 점검해줘.

원본 파일은 수정하지 마.
```

## 완료 프롬프트

```text
점검 결과를 업무노트-템플릿.md 형식에 맞춰
week5/sample-output/참가자-현황-점검.md로 만들어줘.

전체 수치, 문제 행의 근거, 판단 기준, 다음 행동을 포함해줘.
파일을 만들기 전에 목차와 예상 수치를 먼저 보여줘.
```
