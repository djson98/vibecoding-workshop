# 2026 여름 워크숍 참가자 현황 점검 요청

## 요청 정보

- 요청자: 워크숍 운영팀
- 요청일: 2026-07-21
- 제출 마감: 2026-07-18
- 점검 대상: `참가자-현황.csv`

## 해야 할 일

1. 전체 참가자 수를 확인한다.
2. 이름, 이메일, 제출상태의 누락값을 찾는다.
3. 이메일 주소가 같은 참가자를 중복으로 표시한다.
4. 제출상태는 `제출` 또는 `미제출`만 정상값으로 인정한다.
5. 마감일까지 제출하지 않은 참가자를 연락 대상으로 정리한다.
6. 결과에는 원본 행 번호와 판단 이유를 남긴다.

## 주의사항

- 원본 CSV는 수정하지 않는다.
- 이름이나 상태를 추측해 채우지 않는다.
- 이메일이 없거나 상태가 불명확하면 `확인 필요`로 분류한다.
- 결과는 Markdown 업무 노트 초안으로 만든다.
