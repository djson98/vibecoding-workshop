권한 — 파일·명령 실행 전에 물어봅니다

Claude Code는 코드 편집·터미널 명령 실행 전 항상 사용자 확인을 받습니다. 처음에 매번 묻는 건 정상이고, 안전을 위한 디자인입니다.
1. ALLOW ONCE
이번 한 번만 허용
2. ALLOW ALWAYS
앞으로 같은 작업 자동 허용
3. DENY
거부하고 다른 방법 제안받기
* 허용한 권한 관리·해제는 /permissions

백업과 권한

BACKUP
백업

PLAN MODE — /plan

PLAN MODE — 실제 실행은 일어나지 않습니다
다음과 같이 폴더를 정리하겠습니다:

RAG란?

Retrieval-Augmented Generation — AI가 머릿속 지식만으로 답하는 것이 아니라, 자료를 직접 참고하면서 답하는 방식입니다.

예) 논문 5편이 든 폴더를 던지면, 지어내지 않고 원문 페이지에서 근거를 찾아 답을 구성합니다.

메타데이터로 이름 정리

쌓인 PDF를 다루기 전에, 파일명부터 일괄로 정돈합니다. 메타데이터(저자·연도·제목)를 읽어 일관된 형식으로 재명명하면 이후 작업이 훨씬 수월해집니다.

> papers/ 폴더의 모든 PDF에서 메타데이터를 읽어,
{저자}_{연도}_{제목30자}.pdf 형식으로 일괄 재명명해줘.
메타데이터가 비어있는 파일은 본문 첫 페이지에서 추출해줘.
결과 예시
Hwang_2025_Dataset_on_Takeover_During_Dis.pdf
Hwang_2025_Effects_of_In_Vehicle_Auditor.pdf
Lim_2024_Context_Aware_Mental_Health_Sel.pdf
Lee_2024_S_ADL_Smartphone_Based_ADL_for.pdf
Kang_2023_K_EmoPhone_Mobile_and_Wearable.pdf

표와 수치 추출

논문에서 반복해서 옮기는 데이터는 파일로 뽑아두는 게 좋습니다.

> paper.pdf의 Table 2를 CSV 파일로 추출해줘.
모든 행과 열을 빠짐없이 포함하고,
파일명은 table2.csv로 저장해줘
> paper.pdf에서 n, p-value, 95% 신뢰구간,
효과 크기, 평균과 표준편차를 추출해서
results_summary.json으로 저장해줘
> paper.pdf의 Figure 2, 3을
figures/ 폴더에 png로
저장하고 캡션도 captions.md로 정리해줘
스캔본 PDF는 텍스트가 그림으로 들어있어 바로 추출되지 않습니다. 먼저 OCR로 텍스트화하도록 요청한 다음 위 작업을 진행합니다 (예: > scanned.pdf를 OCR로 텍스트화한 뒤 표를 추출해줘).
